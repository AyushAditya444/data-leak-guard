# Evaluation report

_Generated by `python -m leakguard.evaluation report`. Do not edit by hand._

## What was measured

- Datasets: **test** (1500 messages), **handwritten** (59 messages). All data is synthetic or hand-written; no real person's data is used.
- **Matching rule:** a detection is correct when it has the **same type** as a gold span and **overlaps** it; each gold span and each detection is matched at most once.
- **Coverage:** share of gold characters hidden by *any* detection, whatever its type. This is the leak metric: 100% means nothing of that value reached the LLM.
- **Exact:** share of correct detections whose boundaries match the gold span exactly.
- Thresholds were tuned on the **dev** split only; the numbers below are from data the tuning never saw.
- **Name model:** `xlmr-hrl` = `Davlan/xlm-roberta-base-ner-hrl@253f557`, ONNX int8, 280 MB, 1 CPU thread(s). Chosen on dev: see [ner-comparison.md](ner-comparison.md).

## Methodology notes

- After the final round of dev-set tuning, the test-set errors were inspected once. They revealed one defect class the dev set did not contain: key names with a prefix (`DB_PASSWORD=...`, `db_password: ...`). A dev template with that pattern was added, the detector was fixed against dev, and the report regenerated. Test SECRET recall before this fix was 72.9%; the test set was not used for any other decision.
- UPI recall on the test split is pulled down by one hard template with two unknown UPI handles per message; see *Known-hard formats*.
- Phase 4 extended the dataset (name forms, separate dev/test name pools, capitalised words that are not names). The seeded generator therefore produced new samples, so non-NAME rows moved slightly from the Phase 3 report. The name model, its threshold and int8 mode, and the cue-based fallback for lowercase/all-caps names were all chosen on dev only; no test-set inspection informed any Phase 4 decision.
- The cue phrases of the name fallback (e.g. `mera naam ... hai`, `... bol raha hoon`) were written by the same author as the message templates, so the fallback's test numbers may be optimistic. The hand-written set and the lowercase test template without any cue (`bhaiya ... ko parcel de dena`) are the more independent checks.
