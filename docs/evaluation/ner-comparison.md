_Generated by `python -m leakguard.ner.compare`. Do not edit by hand._

- Data: the **dev** split (1500 messages). The test split is never used here; its numbers are only reported in [report.md](report.md).
- **As deployed:** all rule detectors (including the cue-based fallback for lowercase and all-caps names) plus the model, merged. **Model alone:** the same without the cue fallback, to show what the model itself can do.
- Tuned per candidate on dev: the score threshold (best NAME F1 over 0.3, 0.4, 0.5, 0.6, 0.7, 0.8, 0.9) and the int8 quantisation mode (one scale per tensor or per channel).
- Latency: the model alone, best of 3 runs per message, 1 CPU thread, int8.
- Not a candidate: `ai4bharat/IndicNER`. It is gated on Hugging Face (download needs a logged-in account that accepted its terms), so a stranger could not build the guard with one command.
