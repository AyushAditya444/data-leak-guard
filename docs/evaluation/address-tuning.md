## Place stop list

Post office names matched outside addresses on dev were listed; those that are everyday English or Hinglish words, or festival names, were added to `src/leakguard/data/place_stopwords.txt` (never a word added only to fix one sample). Person surnames that are also village names were NOT added: instead, an address that overlaps a name absorbs it, so no part of the name leaks.

Added on dev: `late`, `main`, `dena`, `tak`, `khata`, `naya`, `both`, `same`, `mango`, `bank`, `royal`, `diwali`, `raksha`, `bandhan`, `guru`.
